# Jeremy Moore — Portfolio Website

This is your personal website. It's built from plain, simple files — no special
software needed to edit it, just a web browser and your GitHub account.

## What's in here

- `index.html` — the entire website (all your text lives in this file)
- `css/styles.css` — controls colors, fonts, and layout
- `js/main.js` — a small bit of code that highlights the current section as you scroll
- `assets/images/jeremy-moore-headshot.jpg` — your photo
- `assets/resume/Jeremy-Moore-PMP-Resume.pdf` — your downloadable resume

## How to edit the text

1. Go to your repository on GitHub.com.
2. Click on `index.html`.
3. Click the pencil (✏️) icon in the top right to edit.
4. Find the text you want to change (it's plain English between `<p>` and `</p>`
   tags — just edit the words, leave the `<...>` bits alone) and type your changes.
5. Scroll down and click **"Commit changes"** to save. Your live site updates
   automatically within a minute or two.

## How to swap your photo or resume

1. In your repository, open the `assets/images` or `assets/resume` folder.
2. Delete the old file, then use **"Add file" → "Upload files"** to upload the
   new one.
3. **Important:** the new file must have the *exact same name* as the old one
   (`jeremy-moore-headshot.jpg` or `Jeremy-Moore-PMP-Resume.pdf`), or you'll
   also need to update the file name inside `index.html` in a couple of places.

## How to publish the site for free with GitHub Pages

GitHub Pages is a free hosting service built into GitHub. Once it's turned on,
it automatically publishes whatever is in this repository as a live website —
every time you save a change, the site updates itself within a minute or two.

**Steps (only needs to be done once):**

1. On GitHub.com, create a new **public** repository — for example, name it
   `jeremymoore-portfolio`. You don't need to add a README or any template
   files; just create the empty repository.
2. Open the new repository and click **"Add file" → "Upload files."**
3. Drag in all the files and folders from this project (`index.html`, the
   `css` folder, the `js` folder, the `assets` folder, and this `README.md`),
   keeping the folder structure exactly as it is. Commit the upload.
4. In the repository, click **Settings** (top menu), then **Pages** (left
   sidebar).
5. Under "Build and deployment," set **Source** to **"Deploy from a branch."**
6. Set **Branch** to **main** and the folder to **/ (root)**, then click
   **Save**.
7. Wait 1–2 minutes, then refresh the Pages settings page. Your live web
   address will appear at the top — something like:
   `https://your-username.github.io/jeremymoore-portfolio/`
8. That's it! Share that link. Any future edit you save on GitHub will
   automatically republish to that same address.
